# 오늘 쓸 글, 데이터로 골라주는 서비스

> **관심사·트렌드·북엔드 데이터를 기반으로  
> ‘오늘 쓸 글 주제’와 글 형식을 추천하는 웹·확장 통합 서비스**

---

## 1. 서비스 개요

### 1.1. 한 줄 정의

> **“관심사·트렌드·북엔드 데이터를 기반으로, 오늘 쓸 만한 글 주제와 글 형식을 추천해주는 웹·확장 통합 서비스”**

슬로건(짧은 버전):

> **“오늘 뭐 쓸지 모를 때, 데이터로 골라주는 글감 추천기”**

### 1.2. 서비스 설명 (3줄 요약)

1. 사용자가 관심사 카테고리와 간단한 키워드를 입력하면,  
2. Google Trend, 북엔드 콘텐츠 추천, 커뮤니티 데이터를 결합해 **지금 쓰면 좋은 글 주제 카드**를 생성하고,  
3. 사용자가 선택한 주제와 글 형식을 기록·분석하여, 북엔드 생태계에서의 글쓰기 전환을 높이는 서비스다.

---

## 2. 유저 플로우

### 2.1. 기본 시나리오 (확장 → 웹)

1. 사용자는 **북엔드 확장 서비스(Chrome Extension)**를 통해 진입한다.
2. 확장에서 **로그인 여부**를 확인한다.  
   - 미로그인 → 로그인 페이지(웹/팝업)로 이동  
   - 로그인 → 다음 단계
3. 로그인 후 서버(DB)에서 **관심사 카테고리 존재 여부**를 확인한다.  
   - 있음 → 해당 카테고리를 불러와 기본 필터로 사용  
   - 없음 → “어떤 카테고리인가요?” 온보딩 화면으로 이동하여 관심사 선택/등록
4. 관심사가 설정되면, 사용자는 **사용자 Input**(키워드, 상황 설명 등)을 입력한다.  
   - 예: `“AI 출판 부업 시작”`, `“추천 시스템 공부 기록”`, `“일기 형식 에세이”`
5. 서버는 다음 세 소스를 기반으로 **주제 후보를 생성**한다.
   - Google Trend API
   - 북엔드 기존 콘텐츠/사용 로그 데이터
   - 확장(커뮤니티)에서 인기 있는 주제/선호 패턴
6. 세 데이터를 결합해 **주제 카드 목록(주제 제시)**을 만든다.  
   - 카드 정보: 주제 제목, 요약, 예상 독자, 출처(Trend/Bookend/Community), 점수 등
7. 사용자는 주제 카드 중 하나를 선택하고, 이어서 **글 형식**을 선택한다.  
   - 예: 블로그 글, 뉴스레터, 논문 초록, SNS 스레드 등
8. 선택 결과는 **주제 선택 기록(`user_topic_sessions`)**으로 DB에 저장된다.
9. 이후 플로우:
   - (A) 북엔드/에디터로 딥링크 → 실제 글 작성  
   - (B) 확장 내에서 간단 템플릿/아웃라인만 제공하고 복사하도록 지원

### 2.2. 반복 사용 시나리오

1. 사용자가 다시 확장을 열면, DB에서 기존 관심사를 읽어와 **바로 Input → 주제 추천 단계**로 진입한다.
2. 과거에 선택했던 주제와 유사한 주제를 우선 노출하거나, 아직 쓰지 않은 트렌디한 주제를 강조한다.
3. **“내 기록” 페이지**에서 과거에 선택한 주제/형식을 확인하고, 필요할 경우 같은 주제로 다시 추천을 받을 수 있다.

## 3. 기능 목록

### 3.1. Must-have (이번 프로젝트에서 반드시 구현)

| ID  | 기능명                                      | 설명 |
|-----|---------------------------------------------|------|
| M1  | 사용자 인증 & 계정 관리                    | 이메일/비밀번호 기반 로그인·회원가입 (또는 북엔드 계정 연동). 개인별 관심사·선택 기록 저장. |
| M2  | 관심사 카테고리 설정/불러오기              | 최초 온보딩에서 관심사 선택 후 DB에 저장, 재접속 시 자동 로딩 및 필터로 사용. |
| M3  | 사용자 Input 기반 주제 추천                | 키워드/설명 + 관심사 카테고리를 입력받아 주제 카드 리스트 반환. Google Trends + 북엔드 데이터 + 커뮤니티 데이터 활용. |
| M4  | 주제 선택 & 글 형식 선택 기록              | 사용자가 선택한 주제·글 형식을 세션으로 DB에 저장, “내 기록”에서 조회 가능. |
| M5  | 간단 관리자/기업 지표 1개 이상             | 카테고리별 인기 주제, 글 형식 분포 등 최소 1개의 관리자용 지표 페이지 제공. |

**Must 기능 완료 기준**

- 새 계정 생성 → 로그인 → 관심사 설정 → 키워드 입력 → 주제 추천 → 주제/형식 선택 → “내 기록”에서 이력 확인까지 한 번에 흐름이 동작할 것.
- 관리자 화면에서 최소 1개의 지표(예: 카테고리별 주제 선택 TOP5)가 시각화될 것.
